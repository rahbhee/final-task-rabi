# Learning Log

The explain-back rule: after AI helps you build something, close the chat and write a short paragraph explaining it
in your own words. If you can't, you don't understand it yet. Go back and ask for an explanation, then try again.
Keep one copy of this file in each repo.

## Entry format

Copy this block for every entry.

### YYYY-MM-DD: what I built or learned (a short title)

- **What AI helped with:** one line
- **In my own words (written with the chat closed):** 3 to 6 sentences. What it does, why it is needed, what breaks without it.
- **What I got wrong or was unsure about first:** one honest line
- **One question an interviewer could ask me about this, and my answer:** TODO
